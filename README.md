# Buildoragood - Anime Cartoon Movie Booking Website

## Overview
A modern, visually appealing anime cartoon movie booking website built with HTML, CSS, and JavaScript. Features a vibrant color scheme with smooth animations and an intuitive booking system.

## Features
- 🎬 Movie showcase with anime and cartoon selection
- 📅 Date and time picker for bookings
- 🎟️ Interactive booking form
- 🎨 Beautiful color combination (purple/indigo theme with gradients)
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🔍 Movie search functionality

## Color Scheme
- **Primary**: Indigo (#4F46E5)
- **Secondary**: Purple (#7C3AED)
- **Accent**: Pink (#EC4899)
- **Background**: Gradient from indigo to purple
- **Cards**: White with subtle shadows

## Files
- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive booking functionality
- `README.md` - This file

## How to Use
1. Open `index.html` in any modern web browser
2. Browse available movies on the homepage
3. Click "Book Now" on any movie
4. Fill in your details and select a showtime
5. Submit the booking form for confirmation

## Browser Support
- Chrome (recommended)
- Firefox
- Safari
- Edge
